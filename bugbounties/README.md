## ⚠️ Read before adding anything

**Nothing goes in here without written authorisation from the program.**

- Only publish what the program's disclosure policy explicitly permits.
- Respect embargo periods — many programs require 90 days or written sign-off.
- Redact customer data, internal hostnames, credentials, and anything identifying.
- When in doubt, don't publish. A withdrawn writeup is worse than no writeup.

If a finding isn't cleared for publication, it does not belong in a public repo.
This repository is **public**.
