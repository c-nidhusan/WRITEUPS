# Practice

CTF and lab writeups — TryHackMe rooms, HackTheBox, home lab.

These are **learning** writeups. Published freely, since none of it is real-world target data.

## Format

One folder per machine, named after the room:

```
practice/
└── kenobi/
    ├── PLAN.md        ← written BEFORE deploying, from memory. Not edited afterwards.
    ├── JOURNAL.md     ← real-time log: commands, output, dead ends.
    ├── WRITEUP.md     ← the clean walkthrough, written after.
    └── DEBRIEF.md     ← what I missed, what the notes did and didn't supply.
```

`PLAN.md` is the important one. The gap between what you predicted and what you
needed is the actual measurement of progress. Don't skip it and don't edit it after.
