# 🛡️ Bug Bounties

> My bug bounty hunting journey — training, writeups, and vulnerability research.

I'm a cybersecurity junior training on [TryHackMe](https://tryhackme.com) and working toward a career in bug bounty hunting and offensive security. This repo documents that journey.

## 📁 What you'll find here

- **TryHackMe writeups** — walkthroughs of rooms and learning paths
- **Recon playbooks** — my process for recon, enumeration and asset discovery
- **Vulnerability research** — notes on bug classes (OWASP Top 10, IDOR, XSS, SSRF, auth flaws...)
- **Methodology** — techniques I use in CTFs and labs
